# Документация проекта «Веб-калькулятор»

## 1. Общее описание решения

Проект представляет собой модульное веб-приложение, разработанное на языке Python с использованием фреймворка **Flask**. 
Архитектура построена по модульному принципу:
- `main.py` — точка входа, контроллер маршрутов и обработчик HTTP-запросов (GET/POST).
- `modules/` — вычислительное ядро приложения, разделённое по предметным областям:
  - `arifmetic.py` — базовые математические действия.
  - `geometry.py` — расчет геометрических характеристик фигур.
  - `algebra.py` — решение полиномиальных уравнений.
- `templates/` и `static/` — визуальный интерфейс (HTML + CSS).

## 2. Описание функций и примеры вызова

### 2.1. Модуль `arifmetic.py`

#### `add(a, b)`
- **Назначение**: Сложение чисел.
- **Параметры**: `a (float)`, `b (float)`.
- **Возврат**: `float` — сумма чисел.
```python
result = add(10.5, 4.5)
# result == 15.0
```

#### `subtract(a, b)`
- **Назначение**: Вычитание `b` из `a`.
- **Параметры**: `a (float)`, `b (float)`.
- **Возврат**: `float` — разность чисел.
```python
result = subtract(20, 7)
# result == 13.0
```

#### `multiply(a, b)`
- **Назначение**: Умножение двух чисел.
- **Параметры**: `a (float)`, `b (float)`.
- **Возврат**: `float` — произведение.
```python
result = multiply(6, 7)
# result == 42.0
```

#### `divide(a, b)`
- **Назначение**: Деление `a` на `b` с проверкой деления на ноль.
- **Параметры**: `a (float)`, `b (float)`.
- **Возврат**: `float` результат или `str` с ошибкой.
```python
divide(10, 2)  # 5.0
divide(10, 0)  # 'Ошибка: деление на ноль'
```

#### `power(a, b)`
- **Назначение**: Возведение числа в степень.
- **Параметры**: `a (float)` — основание, `b (float)` — степень.
- **Возврат**: `float`.
```python
result = power(2, 5)
# result == 32.0
```

### 2.2. Модуль `geometry.py`

#### `circle_area(r)` / `circle_perimeter(r)`
- **Назначение**: Вычисление площади и длины окружности.
- **Параметры**: `r (float)` — радиус.
```python
s = circle_area(5)       # 78.5398
p = circle_perimeter(5)  # 31.4159
```

#### `square_area(a)` / `square_perimeter(a)`
- **Назначение**: Площадь и периметр квадрата.
- **Параметры**: `a (float)` — длина стороны.
```python
s = square_area(4)       # 16.0
p = square_perimeter(4)  # 16.0
```

#### `rectangle_area(a, b)` / `rectangle_perimeter(a, b)`
- **Назначение**: Площадь и периметр прямоугольника.
- **Параметры**: `a (float)`, `b (float)` — стороны.
```python
s = rectangle_area(3, 8)       # 24.0
p = rectangle_perimeter(3, 8)  # 22.0
```

#### `parallelogram_area(base, height)` / `parallelogram_perimeter(a, b)`
- **Назначение**: Площадь через основание и высоту; периметр по двум смежным сторонам.
```python
s = parallelogram_area(10, 5)     # 50.0
p = parallelogram_perimeter(5, 7) # 24.0
```

### 2.3. Модуль `algebra.py`

#### `solve_quadratic(a, b, c)`
- **Назначение**: Аналитическое решение уравнения $ax^2 + bx + c = 0$.
- **Параметры**:
  - `a (float)`: Старший коэффициент.
  - `b (float)`: Второй коэффициент.
  - `c (float)`: Свободный член.
- **Возврат**: Кортеж с вещественными корнями либо строка с ошибкой/сообщением.
```python
# Два вещественных корня
solve_quadratic(1, -5, 6)
# (3.0, 2.0)

# Один корень (дискриминант равен нулю)
solve_quadratic(1, 4, 4)
# (-2.0,)

# Нет вещественных корней
solve_quadratic(2, 1, 3)
# 'Нет вещественных корней (D < 0)'

# Ошибка валидации
solve_quadratic(0, 2, 4)
# "Ошибка: коэффициент 'a' не может быть равен нулю"
```

## 4. Примеры запросов к серверу


### Пример 1. Сложение чисел
* **Маршрут:** `/arifmetic`
* **Метод:** `POST`
* **Передаваемые данные:**
  * `a` = 10
  * `b` = 5
  * `operation` = add

```bash
curl -X POST http://127.0.0.1:8080/arifmetic -d "a=10&b=5&operation=add"
```
* **Результат на странице:** `15.0`

---

### Пример 2. Расчет площади параллелограмма
* **Маршрут:** `/geometry`
* **Метод:** `POST`
* **Передаваемые данные:**
  * `figure` = parallelogram
  * `calc` = area
  * `a` = 45
  * `b` = 3

```bash
curl -X POST http://127.0.0.1:8080/geometry -d "figure=parallelogram&calc=area&a=45&b=3"
```
* **Результат на странице:** `135.0`
