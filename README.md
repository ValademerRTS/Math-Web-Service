# Веб-калькулятор (Flask)

Интерактивный веб-калькулятор на базе микрофреймворка Flask, поддерживающий арифметические, геометрические и алгебраические вычисления

## Возможности

- **Арифметика**: сложение, вычитание, умножение, деление и возведение в степень
- **Геометрия**: расчет площади и периметра для круга, квадрата, прямоугольника и параллелограмма
- **Алгебра**: аналитическое решение квадратных уравнений ($ax^2 + bx + c = 0$)

## Установка и запуск

1. Клонирование репозитория:
   ```bash
   git clone https://github.com/ValademerRTS/Math-Web-Service.git
   cd Math-Web-Service  
   ```

2. Создание и активация виртуального окружения:
   ```bash
   python -m venv venv
   
   # На Linux/macOS:
   source venv/bin/activate
   
   # На Windows:
   venv\Scripts\activate
   ```

3. Установка зависимостей:
   ```bash
   pip install -r requirements.txt
   ```

4. Запуск приложения:
   ```bash
   python main.py
   ```
   Приложение будет доступно по адресу: `http://127.0.0.1:8080/`.
